用 Shiki 双主题实现跟随切换的代码高亮

2026/09/20 · 约 3 分钟 · #Astro#前端

博客要支持明暗两套主题，代码块的颜色也得跟着换。记录一下 Astro + Shiki 的具体做法和踩到的坑。

这是一篇示例技术笔记，用来展示排版效果。正文里的强调、链接、 行内代码 defaultColor 都会自动套上样式。

问题是什么

博客支持明暗主题切换之后，正文颜色会跟着变，但代码块不会 —— 因为 Shiki 在构建时就把颜色内联成了十六进制值。

浅色主题下看着正常的颜色，切到深色背景上就糊成一片。

配置写法

// astro.config.mjs
export default defineConfig({
  markdown: {
    shikiConfig: {
      themes: { light: 'github-light', dark: 'github-dark' },
      defaultColor: false,
    },
  },
});

小结

步骤关键点
配置 Shikithemes 传两个主题，defaultColor: false
写 CSS前景色和背景色都要按主题切换
防闪白主题判断脚本必须内联在 <head>
